How it works

  1. 01

    Drop a file

    Excel or CSV. The site works out what each column holds: dates, numbers, emails, IDs or categories.

  2. 02

    Check the guesses

    Change a column type if it is wrong, and tick what you want fixed.

  3. 03

    Download the clean file

    A workbook with the cleaned data, a list of every issue with its row number, and a summary.

Your file stays on your computer

The file is read by your own browser. It is not sent to a server, and nothing is kept after you close the tab.
